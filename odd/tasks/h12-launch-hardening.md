## Decisions this document fixes

1. **The privacy test is the milestone's first deliverable**, because it is the only hard constraint whose stated enforcement does not exist. It proves, from the running app: after the file is chosen, no request leaves the origin, the only worker traffic is same-origin, nothing is written to storage except the theme preference, and no third-party origin appears anywhere in the log.
2. **The privacy test does not test the lint rules**, it tests the behaviour: a future refactor that adds a `fetch` call must fail here even if someone relaxes the ESLint config.
3. **CSP stays honest rather than aspirational.** The shipped header is exactly what the app needs: if the animation layer requires `style-src 'unsafe-inline'`, that is documented with the reason and the alternative considered, instead of leaving a comment that promises a tightening nobody did. `connect-src 'self'` and the absence of third-party origins are non-negotiable.
4. **Lighthouse is measured, not installed.** It runs through `npx lighthouse` against the built app on a documented command line, and the numbers land in the checklist with the commit they belong to. Adding a lighthouse dependency would change the delivery surface for a measurement tool.
5. **`og:image` is generated by our own renderer**, from the app's card drawing code at build time, so the social preview cannot drift from the product and no third-party artwork enters the repo.
6. **The checklist is the acceptance artifact**: every line is a command or an observed number with its evidence path, never a claim.
