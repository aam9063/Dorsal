# Glossary

Domain words as this project uses them. UI copy is Spanish; this glossary is in English because it is developer documentation.

| Term                 | Meaning in Dorsal                                                                                                                                                                                                     |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Export**           | The archive a Strava user requests from their account settings. It arrives as a `.zip` that the user unzips.                                                                                                          |
| **`activities.csv`** | The only file Dorsal reads. It sits at the root of the unzipped export and has one row per activity for the whole account history. Its format is documented in `docs/export-format.md` (H-01).                        |
| **Activity**         | One row of `activities.csv`, normalized into `Activity` (sport, distance, moving time, elevation, heart rate, gear).                                                                                                  |
| **Season 2026**      | Every activity whose local start date falls between 2026-01-01 00:00 and 2026-12-31 23:59:59. Activities from other years are counted and discarded inside the worker; they never reach the main thread.              |
| **Story**            | One full-screen panel of the wrapped, numbered 01 to 08. A story without enough data is omitted and the player adjusts its progress bars.                                                                             |
| **Player**           | The story component that handles advance, back, pause, keyboard and progress bars, respecting `prefers-reduced-motion`.                                                                                               |
| **Archetype**        | A deterministic label derived from the athlete's patterns (early bird, night owl, weekend warrior, methodical, multisport, long distance, steady). Rules live in BRIEF section 6.1.                                   |
| **Gear**             | The equipment recorded in the export's gear column. Grouped per item as "gear of the year": kilometres, hours and activity count.                                                                                     |
| **Bib card**         | The shareable 1080×1920 PNG shaped like a race bib number: distance as the number, name, archetype and three stats.                                                                                                   |
| **`YearSummary`**    | The single serializable object the worker returns, validated with Zod. It holds 2026 aggregates only — never per-activity rows.                                                                                       |
| **Worker**           | The Web Worker that parses the CSV and computes metrics so the main thread stays free. Its API is the only "backend" the app has.                                                                                     |
| **Fixture persona**  | A synthetic export generated by `fixtures/generator/` that exercises one scenario (runner, cyclist, multisport, no gear, few activities, ten years of history, no 2026, year boundaries, broken rows, retired shoes). |
| **Verify run**       | One execution of `pnpm verify`, which drives the real app with Playwright and writes screenshots, console log and network log to `artifacts/verify/<timestamp>/`.                                                     |
| **Work unit**        | A commit small enough to review and revert on its own, with its tests and docs.                                                                                                                                       |
